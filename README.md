🎵 Spotify Listening History Analysis | Power BI Dashboard

📌 Project Overview

This Power BI dashboard analyzes personal Spotify listening history to uncover trends in music consumption, artist preferences, album engagement, listening patterns, and platform usage over time.

The project transforms raw Spotify streaming data into actionable insights through interactive visualizations, custom KPIs, and advanced analytics, helping users better understand their listening behavior and music preferences.

🎯 Objectives

- Analyze listening activity across multiple years
- Track album, artist, and track engagement trends
- Identify peak listening hours and weekly listening patterns
- Compare listening behavior across devices and platforms
- Explore track frequency and listening duration relationships
- Create an interactive and visually appealing Spotify-inspired dashboard

📊 Dashboard Pages

1. Overview Dashboard

Provides a high-level summary of Spotify listening activity.

Key Metrics
- Total Albums Played: 7,907
- Total Artists Played: 4,112
- Total Tracks Played: 13,665

Features
- Year-over-Year comparison
- Platform filters
- Shuffle and Skip analysis
- Trend analysis over multiple years

2. Listening Patterns Dashboard

Analyzes listening behavior across hours and weekdays.

Insights Included
- Listening Hours vs Days Heatmap
- Hourly listening distribution
- Weekly listening activity trends
- Average Listening Time vs Track Frequency Scatter Plot

Interactive Filters
- Year Selection
- Shuffle Status
- Skip Status
- Listening Time Threshold
- Track Frequency Threshold

3. Album Details Dashboard

Detailed album-level analysis including:

- Album Name
- Artist Count
- Track Count
- Album Count
- Total Milliseconds Played
- Average Listening Time

This page enables users to drill into individual albums and evaluate listening engagement at a granular level.

Listening Trends
- Music consumption increased significantly between 2020 and 2022.
- Listening activity remains consistently high across recent years.

Artist Preferences
- The Beatles emerge as one of the most frequently played artists.
- Artist engagement is concentrated among a relatively small set of favorite artists.

Track Engagement
- Several tracks demonstrate exceptionally high replay frequency.
- Average listening time and play frequency reveal strong listener preferences.

Listening Behavior
- Listening activity is higher during evening and late-night hours.
- Weekday listening patterns remain relatively consistent throughout the week.

Platform Usage
- Dashboard supports analysis across:
  - Android
  - iOS
  - Mac
  - Windows
  - Web Player
  - Cast Devices
